# Media pembelajaran Roblox untuk skripsi Achmal

File utama pengembangan: `places/RobloxLearningMedia-WORKING.rbxl`. Buka dan simpan file ini langsung di Roblox Studio. `RobloxLearningMedia-BACKUP.rbxl` milik penelitian pendahulu tetap berada di folder lokal induk dan tidak dimasukkan ke repository.

Repository GitHub ini **private** dan menyimpan place utuh agar pekerjaan di laptop dan beberapa komputer warnet dapat disinkronkan. Baca `ALUR_SINKRONISASI.md` sebelum bekerja.

`default.project.json`, `src/`, dan `src copy/` berasal dari percobaan Rojo/Argon lama. Pemetaan Rojo saat ini belum mencakup seluruh place dan belum menjadi sumber build kanonis. Kedua folder source disimpan sebagai arsip percobaan agar dapat diaudit lintas komputer. Baca `MIGRASI_ROJO_STATUS.md` untuk bukti, batas, dan syarat migrasi penuh. Fitur penelitian baru belum diimplementasikan pada baseline ini.
